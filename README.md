# depobat-deploy

Versiunea compilată a site-ului [depobat.ro](https://depobat.ro), pentru cPanel → Git Version Control.
Generată automat din repo-ul sursă (`scripts/package-cpanel.sh`); nu se editează manual.

**Publicare:** cPanel → Git Version Control → Manage → Pull or Deploy → **Update from Remote** → **Deploy HEAD Commit**.
`deploy.sh` copiază aplicația în `~/depobat-app` și o repornește.
